# Managing model downloads

<Note>
Models for Isaac OS reference applications are downloaded automatically during
their build to be available at runtime. This guide provides additional commands
to share the resource cache across clones and worktrees, and to download an
application's models before building it.
</Note>

## Download models automatically during builds

Replace `<app>` with your application name and build it normally to download and
verify its required models:

```bash
./isaac_os build <app>
```

No separate download command is required. Subsequent builds reuse verified models
from the resource cache.

## Share the cache between worktrees

Use the same cache mounts and environment for every download and build.
For shared worktrees, reuse the existing host cache and export its mapping for every
CLI invocation, for example (replace `<host-cache>` with the existing cache):

```bash
export ISAAC_OS_EXTRA_DOCKER_RUN_ARGS='-v <host-cache>:/cache/isaac-os -e CPM_SOURCE_CACHE=/cache/isaac-os/cpm -e ISAAC_RESOURCE_CACHE=/cache/isaac-os/resources'
```

## Warmup your model cache

To download an application's models and resources before building it:

```bash
./isaac_os build <app> --target isaac_download_resources
```

For one model or resource, replace `<resource-target>` with its target name:

```bash
./isaac_os build <app> --target <resource-target>
```

<Accordion title="Example: GR00T N1.7 + WBC">

Download all models for the GR00T N1.7 + WBC application:

```bash
./isaac_os build gr00t_n1_7_wbc_g1 --target isaac_download_resources
```

Download only its apple-to-plate model bundle:

```bash
./isaac_os build gr00t_n1_7_wbc_g1 --target gr00t_n1_7_g1_apple_to_plate_models
```

</Accordion>
